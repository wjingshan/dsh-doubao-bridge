# 豆包工作台清单（2026-11 版）

豆包把首页改成了「工作台」（`/chat/workbench`）：22 个场景化工作台，选定后成为
「当前工作台」，之后的对话都在那个场景的提示词与工具集下进行。切换方式：
左侧「工作台」→ 找到目标卡片 → 点「使用」，顶部徽标会变成该工作台名字。

编程开发工作台的内置快捷任务（截图实测）：

- 应用生成
- 代码故障诊断与修复
- 代码库理解与架构梳理
- 代码变更审查
- 代码库变更方案设计
- 性能分析与优化

输入框下方可挂：本地电脑目录、项目、技能、插件，权限可选「全部允许 / 自动」。

## 22 个工作台 → 能力与适用场景

| 工作台 | 能力范围 | 什么时候选它 |
| --- | --- | --- |
| **编程开发** | 读懂仓库、定位问题、生成应用、交付可验证结果；应用生成/故障修复/架构梳理/变更审查/变更方案/性能优化 | 改代码、查 bug、架构分析、性能调优、写新应用 |
| **数据分析** | 上传数据后的异常定位与多表核对，不依赖新建 BI 系统 | 给一堆表格/CSV 找异常、对账、多表交叉核对 |
| **产品项目** | 产品经理与小团队负责人，从反馈取舍到版本交付的完整材料链路 | 需求梳理、版本规划、验收材料 |
| **游戏制作** | 玩法设计、编码实现、平台接入、调试测试、发布准备 | 小游戏从设计到上线 |
| **创意设计** | 图片与视频创作者一站式：电商详情页、营销海报、社媒配图、TVC 广告、口播带货、产品种草 | 视觉产出、海报、详情页、短视频素材 |

## 使用约定

- **默认**：按项目性质选。改代码 → 编程开发；数据核对 → 数据分析；视觉产出 → 创意设计；
  视频后期 → 视频组装；长文写作 → 写作/剧情创作；正式文书 → 正式材料。
- **跨类任务不硬塞**：一个任务同时涉及代码和设计时，按「主要交付物」选工作台，
  在任务文本里写清另一部分的要求。
- **工作台不是硬门槛**：它主要影响豆包的默认提示词与快捷任务。任务文本里写清楚要求
  仍然是最有效的控制手段。
